👥 System Users

👤 Member

Search books, view book details, borrow books, return books, reserve books and view borrowing history.

👩‍💼 Librarian

Manage books, members, borrowing records, returns, reservations and fines.

🧑‍💻 Administrator

Manage user accounts, system information and generate reports.

🔐 Nonfunctional Requirements

⚡ Performance

Book searches should respond quickly.

🔐 Security

User accounts and system information should be protected.

😊 Usability

The system should be easy to use and understand.

🛡️ Reliability

The system should operate reliably during normal usage.

📈 Scalability

The system should support future growth.

💾 Backup & Recovery

Data should be protected through backup and recovery mechanisms.

⚙️ Functional Requirements

📚 Book Management

Add, update, delete and search books.

👥 Member Management

Manage member information and accounts.

📖 Borrowing

Manage book borrowing and returning.

🔖 Reservations

Create and manage book reservations.

💰 Fines

Calculate and manage overdue fines.

📊 Reports

Generate reports and statistics.

🎭 System Actors

👤 Member

Uses library services and manages personal borrowing activities.

👩‍💼 Librarian

Manages daily library operations.

🧑‍💻 Administrator

Manages system users and administrative functions.
