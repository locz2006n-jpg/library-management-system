🔗 Library Management System – Use Case Diagram

The system has three main actors: Member, Librarian and Administrator.

👤 Member

  • Login
  • Search Book
  • View Book Details
  • Borrow Book
  • Return Book
  • Reserve Book
  • View Borrowing History

👩‍💼 Librarian

  • Manage Books
  • Manage Members
  • Manage Borrowing
  • Manage Reservations
  • Calculate Fine
  • Pay Fine
  • Generate Reports

🧑‍💻 Administrator

  • Login
  • Manage User Accounts
  • Generate Reports
  • Send Notifications

🔗 Main Use Cases

🔐 Login

User authenticates to access the system.

🔎 Search Book

Member searches for available books.

📖 Borrow Book

Member borrows an available book.

↩️ Return Book

Member returns a borrowed book.

🔖 Reserve Book

Member reserves an unavailable book.

💰 Calculate Fine

System calculates overdue fines.
